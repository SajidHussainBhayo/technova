
# TechNova - React Homepage

1. This project is a modern technology homepage built using React.
2. I used Vite to create and run the React application.
3. I selected React Bootstrap as my UI library.
4. I installed it using: npm install react-bootstrap bootstrap
5. The homepage contains Navbar, Hero, Features and Footer components.
6. React Bootstrap saved me from creating navigation bars, buttons and cards manually.
7. The project can be started using npm run dev.
